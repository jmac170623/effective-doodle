# Travel Exchange 365

Marketing website for **Travel Exchange 365**, a trip-exchange and booking
marketplace. Static HTML/CSS/JS — no build step, no dependencies.

## Structure

```
index.html       Single-page site (Home, How It Works, Destinations, Plans, About, Contact)
css/styles.css    Styles
js/script.js      Mobile nav, active-link highlighting, back-to-top, form validation
```

## Running locally

Any static file server works, e.g.:

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
